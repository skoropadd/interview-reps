# Sources for the question library

The cards in `tasks/25_library_cards.json` were written for this library. Public interview-question lists were used only to
decide WHICH questions are worth a card; no answer text was copied.

| Source | What it was used for | Licence shown |
|---|---|---|
| [amitshekhariitbhu/ai-engineering-interview-questions](https://github.com/amitshekhariitbhu/ai-engineering-interview-questions) | LLM, RAG, agents and evaluation topics | Apache-2.0 |
| [llmgenai/LLMInterviewQuestions](https://github.com/llmgenai/LLMInterviewQuestions) | LLM basics, RAG, fine-tuning topics | none shown |
| [singhsidhukuldeep Interview-Questions: A/B testing](https://singhsidhukuldeep.github.io/Interview-Questions/AB-testing) | Experiment-design topics | none shown |
| [youssefHosni/Data-Science-Interview-Questions-Answers](https://github.com/youssefHosni/Data-Science-Interview-Questions-Answers) | Deep-learning topics | licence file present, type not read |
| [alirezadir/Machine-Learning-Interviews](https://github.com/alirezadir/Machine-Learning-Interviews) | The idea of an ML-coding module (`tasks/mlcoding/`); tasks and tests written here | MIT |

Tasks that link to NeetCode or LeetCode are solved on those sites; only the title and link are stored here.
