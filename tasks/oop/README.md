# OOP coverage map

The topic list follows NeetCode's "Python OOP" course (6 sections, 37 lessons). The course teaches each idea with a filled-in
template; the exercises here ask for the same ideas from a blank file, with tests, and the find-the-bugs and read-and-explain
tasks check that you can read someone else's classes.

| Course section | Ideas | Exercise here | Also |
|---|---|---|---|
| 1. Classes and objects | attributes, methods, `self`, `__init__` | `oop_01_bank_account` | `oop_02_money` (`__eq__`, `__hash__`, `__repr__`) |
| 2. Encapsulation | public, `_protected`, `__private`, getters and setters, `@property` | `oop_07_property` | |
| 3. Class attributes | class vs instance attributes, `@classmethod`, `@staticmethod` | `oop_08_class_methods` | `explain_01_models` |
| 4. Inheritance | overriding, `super()`, multiple inheritance, method resolution order | `oop_03_savings_account` | `explain_01_models`, theory cards on MRO |
| 5. Polymorphism | same call on different classes, duck typing, no overloading in Python | `oop_04_abstract_model` | theory cards |
| 6. Abstraction | `ABC`, `@abstractmethod`, interfaces | `oop_04_abstract_model`, `oop_06_vectors` | `debug_02_vectors` |
| Not in the course | container methods (`__len__`, `__getitem__`, `__iter__`), exceptions | `oop_05_dataset` | `explain_03_loader`, `debug_01_pipeline` |

After these come three design tasks from NeetCode Core Skills, solved on their site: dynamic array, hash table, double-ended queue.
